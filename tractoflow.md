# TractoFlow

## Overview

TractoFlow is a fully automated, production-ready processing pipeline for diffusion magnetic resonance imaging (dMRI) data that performs end-to-end analysis from raw diffusion-weighted images to tractography-based connectivity matrices and white matter statistics. Developed by the Sherbrooke Connectivity Imaging Laboratory (SCIL) at Université de Sherbrooke, TractoFlow orchestrates a sequence of preprocessing steps—including motion correction, eddy current correction, skull stripping, diffusion tensor estimation, and probabilistic tractography—while maintaining full compatibility with the [[bids]] data organization standard [[Theaud20]]. The pipeline produces outputs in standard neuroimaging formats (NIfTI, CSV) that can be directly consumed by downstream connectomics tools such as [[brain-connectivity-toolbox]], [[graphvar]], or [[the-virtual-brain]] for whole-brain modeling applications [[SanzLeon13]].

## Motivation and Context

Diffusion MRI has become the primary modality for non-invasive mapping of white matter structure in vivo, enabling reconstruction of white matter tracts via tractography and quantification of microstructural integrity through metrics like [[fractional-anisotropy]] (FA) and mean diffusivity (MD) [[LeBihan01]]. However, processing raw dMRI data involves numerous complex steps—each with multiple algorithmic choices—that must be performed consistently across subjects and sessions to yield reliable results. Manual processing is error-prone, difficult to reproduce, and does not scale to large datasets such as the [[hcp-dataset]] or [[uk-biobank]]. TractoFlow addresses this problem by providing a standardized, validated, and containerized pipeline that automates the entire diffusion processing workflow with minimal user configuration. Its development was driven by the growing need for reproducible pipelines in large-scale neuroimaging consortia and the broader open science movement championed by platforms like [[brainlife]] and [[openneuro]].

## Technical Implementation

TractoFlow is implemented as a [[nextflow]] workflow, which provides a domain-specific framework for chaining together heterogeneous neuroimaging tools into coherent processing pipelines [[DiTommaso17]]. The pipeline integrates several established software packages: [[fsl]] for eddy current correction and brain extraction [[Jenkinson12]], [[mrtrix3]] for robust estimation of fiber orientation distributions and response functions [[Tournier19]], [[ants]] for spatial normalization [[Avants09]], and [[dipy]] for diffusion tensor imaging metrics [[Garyfallidis14]]. Each processing step is implemented as an independent processing node, allowing for parallel execution on high-performance computing clusters and flexible debugging.

The core processing sequence in TractoFlow consists of the following stages. First, the raw dMRI data undergo rigorous quality control including outlier detection and intensity normalization using MRtrix3's dwidenoise. Second, preprocessing includes correction for motion artifacts and eddy currents using FSL's eddy and topup tools, followed by brain extraction using FSL's BET. Third, diffusion tensor imaging (DTI) metrics are estimated using DIPY's tensor fitting, producing FA, MD, radial diffusivity (RD), and axial diffusivity (AD) maps. Fourth, response functions are computed for fiber orientation distribution estimation using constrained spherical deconvolution. Fifth, probabilistic tractography is performed using the anatomically-constrained particle filter tracking algorithm with default parameters optimized for whole-brain tracking. Finally, tractography results are segmented into a user-specified parcellation (e.g., [[desikan-killiany-atlas]] or [[schaefer-atlas]]), and connectivity matrices are generated by counting streamlines between region pairs.

TractoFlow supports multiple output formats and can generate both voxel-wise diffusion maps and tract-wise statistics. The pipeline is executable via command-line interface, Docker, or Singularity/[[apptainer]] containers, ensuring reproducibility across computing environments [[Kurtzer17]].

## Relationship to TVB and Whole-Brain Modeling

TractoFlow plays an important role in the [[whole-brain-modeling]] ecosystem by providing the structural connectivity estimates that serve as anatomical scaffolds for neural mass models. The [[structural-connectivity]] matrices generated by TractoFlow—typically comprising streamline counts or densities between cortical and subcortical regions—are directly imported into simulation environments such as [[the-virtual-brain]] (TVB) to constrain the strength and delays of inter-regional coupling [[SanzLeon13]]. The quality of the structural connectome critically influences the dynamics of whole-brain models, affecting phenomena such as [[brain-oscillations]], resting-state networks, and transitions between dynamical regimes.

TVB accepts structural connectivity inputs in various formats, and TractoFlow's output can be adapted using tools like [[connectome-workbench]] or custom Python scripts to match TVB's required schema—including the connectivity matrix, region labels, and optional tract length estimates. Furthermore, TractoFlow's ability to generate subject-specific connectomes enables [[personalized-brain-modeling]], where individual white matter architecture informs patient-specific simulations in applications ranging from [[epilepsy-modeling]] to [[alzheimers-modeling]]. The pipeline thus serves as a critical bridge between empirical diffusion imaging and computational neuroscience frameworks.

## Key Features

TractoFlow offers several notable features that distinguish it from alternative dMRI processing pipelines. Its BIDS compatibility ensures that raw data can be organized according to community standards, facilitating data sharing and collaboration [[Gorgolewski16]]. The pipeline implements automated quality control at each stage, flagging problematic datasets before they propagate through downstream analyses. Its containerized deployment via Docker and Singularity eliminates the "works on my machine" problem and enables bit-exact reproducibility. TractoFlow also provides pre-configured workflows for common parcellation schemes, reducing the technical barrier for new users. Finally, the pipeline integrates seamlessly with the [[brainlife]] platform, allowing users to execute TractoFlow through a web interface and access results programmatically via APIs.
