# Scona

## Overview

**Scona** (Structural COvariability Network Analysis) is a Python-based software toolbox designed for the analysis of structural covariance networks derived from [[neuroimaging]] data, particularly gray matter volume or cortical thickness measurements obtained via magnetic resonance imaging (MRI). Unlike [[functional-connectivity]] analyses that examine time-series correlations between brain regions, structural covariance networks quantify the degree to which regional morphometric properties (such as volume or thickness) co-vary across individuals within a population, providing insights into shared [[developmental-trajectories]], [[aging]] patterns, or pathological alterations. The toolbox implements a comprehensive set of graph-theoretic metrics and network analysis methods, enabling researchers to construct, characterize, and compare structural covariance graphs at both individual and group levels.

## Key Features

Scona provides an integrated environment for constructing structural covariance networks from neuroimaging-derived parcellations, with support for various brain atlases including the Desikan-Killiany atlas, [[destrieux-atlas]], and automated parcellations such as those generated by FreeSurfer. The software implements graph theory metrics including node degree, strength, betweenness centrality, clustering coefficient, path length, [[modularity]], and [[rich-club]] coefficients, enabling detailed characterization of network topology. Beyond basic metrics, scona offers advanced analyses such as network-based statistic (NBS) for identifying subnetworks exhibiting significant group differences, bootstrap confidence intervals for metric estimation, and tools for comparing network properties across different populations or experimental conditions. The toolbox also integrates seamlessly with common Python neuroimaging libraries, particularly nilearn and [[nibabel]], facilitating interoperability with preprocessing pipelines and visualization tools.

The software implements several approaches for constructing structural covariance matrices, including Pearson correlation, partial correlation with regularization (LASSO or ridge regression), and covariance-based methods. Researchers can threshold these matrices using absolute density thresholds, weight retainment strategies, or consensus-based approaches to generate binary or weighted graphs suitable for graph-theoretic analysis. Scona also supports longitudinal analysis, allowing examination of how structural covariance networks change over time within individuals or across developmental trajectories.

## Relationship to TVB

While scona is designed primarily for analyzing structural covariance networks from morphological MRI data, its relationship to [[the-virtual-brain]] (TVB) lies in the shared goal of characterizing brain network organization. Structural covariance networks derived from scona can serve as empirical constraints for [[whole-brain-modeling]] approaches in TVB, where the covariance structure informs the coupling weights between brain regions in connectome-based simulations. The morphometric similarities across individuals captured by scona reflect underlying shared connectivity patterns that can be related to [[structural-connectivity]] estimates derived from diffusion imaging. Furthermore, both scona and TVB address questions of [[network-dynamics]] and brain organization, albeit through different methodologies—scona uses observational morphometric data while TVB employs computational modeling to simulate brain dynamics.

## Technical Implementation

The toolbox is implemented in Python and follows a modular architecture where users can construct networks, compute graph metrics, and perform statistical comparisons through a consistent interface. Core functionality includes data loading from CSV or matrix formats, network construction via correlation or covariance estimation, application of graph thresholds, metric computation using vectorized operations for efficiency, and visualization of networks and associated metrics. Scona supports both weighted and unweighted network analyses, with options for edge weight normalization and multiple thresholding strategies. The software handles large-scale parcellations (e.g., parcellations with 100–1000 regions) efficiently through NumPy-based implementations.

## Related Software

Scona operates within the broader ecosystem of brain connectivity analysis tools. Related toolboxes include the [[brain-connectivity-toolbox]] (BCT) and [[brain-connectivity-toolkit]] (BCTpy), which provide comprehensive graph-theoretic analyses for functional and structural networks. For [[connectomics]] research, [[nilearn]] offers machine learning utilities for brain parcellation and connectivity analysis, while [[freesurfer]] provides the cortical reconstruction that often serves as input to structural covariance analyses. The [[graph-tool]] library provides alternative implementations of graph-theoretic algorithms with enhanced performance for large networks. Researchers interested in [[dynamic-causal-modeling]] or [[whole-brain-modeling]] may use scona-derived networks as empirically-grounded connectivity templates for computational simulations in [[the-virtual-brain]] or similar platforms.
