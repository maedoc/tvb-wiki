Plotly is an open-source interactive graphing library that supports multiple programming languages, including Python, R, JavaScript, and MATLAB. Originally developed as a JavaScript library for creating web-based interactive plots, Plotly has evolved into a comprehensive visualization ecosystem used in scientific research, data science, and educational contexts (Plotly, 2024). The Python implementation, plotly.py, has become prominent in the computational neuroscience community due to its ability to create publication-quality interactive figures that can be embedded in Jupyter notebooks, web applications, or exported as standalone HTML files. Unlike static visualization libraries that produce fixed images, Plotly generates visualizations with built-in interactivity—including zooming, panning, hovering for data inspection, and animated transitions—that allow researchers to explore complex multidimensional datasets in ways that static plots cannot accommodate.

## Role in Computational Neuroscience

In the context of whole-brain modeling and computational neuroscience, Plotly is frequently used for visualizing the outputs of large-scale brain simulations and neuroimaging data analyses. Researchers working with [[the-virtual-brain]] (TVB) may employ Plotly to generate interactive representations of simulated brain activity, including time series from neural mass models, connectivity matrices derived from [[structural-connectivity]] data, and dynamic patterns of [[brain-oscillations]] across cortical regions. The library's support for 3D surface rendering can be valuable for visualizing brain network topology, enabling researchers to display [[brain-network]] nodes and edges superimposed on cortical meshes derived from neuroimaging atlases such as the [[desikan-killiany-atlas]] or [[glasser-atlas]].

Plotly can be used alongside [[nilearn]]—a popular Python library for neuroimaging data analysis—to visualize statistical maps, activation patterns, and connectivity results in standardized neurological space (MNI space). While nilearn's native plotting backend is matplotlib, researchers may use Plotly for complementary visualization workflows (Nilearn developers, 2024).

Beyond static brain mapping, Plotly is well-suited for displaying complex dynamical systems outputs that emerge from whole-brain modeling. Researchers studying [[epilepsy-modeling]] may use Plotly to visualize seizure propagation patterns across cortical surfaces, while those investigating [[brain-stimulation]] paradigms can employ its 3D capabilities to model electric field distributions. The ability to create linked subplots that share axes and selection states can be useful for exploring relationships between [[functional-connectivity]] patterns observed in [[fmri]] or [[meg]] data and predictions generated by computational models such as the [[wong-wang-model]] or [[jansen-rit-model]].

## Key Features

Plotly provides several features relevant to neuroscience applications. First, the library supports more than 50 chart types including scatter plots, line plots, surface plots, 3D meshes, and specialized scientific visualizations (Plotly, 2024). For [[brain-connectivity-toolbox]] users, heatmap and network graph capabilities can enable display of connectivity matrices and [[graph-theory]] metrics. Second, Plotly figures render in interactive HTML format with no additional dependencies—a feature useful when sharing results via platforms like [[brainlife]] or depositing data in repositories like [[openneuro]]. Third, the library provides customization options through its API, allowing researchers to control colorscales, annotations, layout properties, and animation sequences.

The Python implementation integrates with the scientific Python ecosystem, including [[pandas]] for data manipulation, [[numpy]] for numerical computing, and [[scipy]] for statistical analysis. This interoperability means that outputs from [[neural-mass-model]] simulations or [[parameter-estimation]] procedures can be directly visualized without format conversion. Plotly also supports animation frames, enabling researchers to create videos of evolving brain states—useful for visualizing [[network-dynamics]] in [[spiking-neural-networks]] or showing how [[synaptic-plasticity]] shapes connectivity over simulation time.

## Relationship to TVB and Related Tools

Plotly occupies a complementary role relative to other visualization tools used in the TVB ecosystem. While [[matplotlib]] remains widely used for generating static publication figures and is integrated into TVB's default rendering pipeline, Plotly provides interactivity suitable for modern web-based brain atlases and interactive notebooks. Researchers often use both: matplotlib for initial exploration and static figures in papers, Plotly for interactive visualizations in tutorials, web applications, and collaborative workspaces. The [[brainnet-viewer]] tool, specifically designed for displaying brain networks on 3D surfaces, shares conceptual overlap with Plotly's 3D capabilities but provides domain-specific features like automated atlas mapping.

Plotly's relationship to [[seaborn]]—another statistical visualization library built on matplotlib—is complementary: seaborn excels at statistical graphics with sophisticated aesthetic defaults, while Plotly prioritizes interactivity and web deployment. For researchers working with [[connectome]] data from the [[hcp-dataset]], Plotly provides a flexible framework for visualizing individual subject variability in connectivity patterns, while specialized tools like [[connectome-workbench]] handle domain-specific file formats like CIFTI.

## Open Questions and Limitations

Plotly presents certain limitations for neuroscience applications. Large-scale connectivity matrices or high-resolution cortical meshes can cause performance degradation in web-based rendering, particularly when using 3D surface plots with thousands of vertices. The library's abstraction layer, while convenient, sometimes obscures low-level WebGL commands, limiting optimization opportunities for specialized visualizations. Additionally, while Plotly supports exporting to static image formats (PNG, SVG, PDF), achieving exact visual fidelity between interactive HTML and print output sometimes requires manual adjustment.
