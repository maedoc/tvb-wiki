# BCI2000

## Overview

BCI2000 is a general-purpose, open-source software platform for brain-computer interface (BCI) research and development. First released in 2000, BCI2000 was developed at the Wadsworth Center of the New York State Department of Health in Albany, New York, with substantial contributions from the Institute of Medical Psychology and Behavioral Neurobiology at the University of Tübingen. The project has been supported by NIH grants and is currently maintained by the National Center for Adaptive Neurotechnology. BCI2000 provides a modular framework for acquiring, processing, and analyzing neurophysiological signals in real time. The system supports multiple data acquisition hardware platforms and signal processing pipelines, making it one of the most widely adopted BCI research platforms in the world. BCI2000 is designed to be flexible enough for both novice researchers conducting simple cursor control experiments and advanced investigators building complex neuroadaptive interfaces for [[brain-stimulation]] applications.

## Key Features

BCI2000's architecture follows a modular pipeline design consisting of four primary components: the Source module (handling data acquisition from EEG, MEG, or other biosignal hardware), the Signal Processing module (performing feature extraction and classification), the Application module (implementing the BCI paradigm and user feedback), and the Operator module (providing graphical user interface control). This separation of concerns allows researchers to mix and match components or implement custom modules while maintaining compatibility with the broader ecosystem. The platform supports low-latency real-time signal processing, which is critical for closed-loop BCI applications where neural signals must be decoded and fed back to the user within milliseconds.

The software includes built-in implementations of common BCI paradigms including P300 event-related potentials for spelling interfaces (originally described by Farwell & Donchin, 1988), motor imagery classification using common spatial patterns, steady-state visual evoked potentials, and adaptive algorithms that adjust to individual users' neural signatures over time. BCI2000's protocol specification format allows experiments to be described in a structured, human-readable format, facilitating replication and sharing across laboratories. The platform has been extended through numerous contributed modules supporting advanced analyses such as spectral decomposition, spatial filtering, and [[connectivity]] metrics relevant to [[neural-mass-model]] development.

## Relationship to The Virtual Brain

While BCI2000 and [[the-virtual-brain]] (TVB) serve different primary purposes—BCI2000 focuses on real-time neural signal acquisition and decoding while TVB specializes in large-scale [[whole-brain-modeling]] and simulation—they share conceptual territory in their treatment of brain dynamics. BCI2000 experiments generate the empirical EEG and MEG data that can inform [[parameter-estimation]] procedures for whole-brain models. Conversely, predictive models developed in TVB frameworks could theoretically provide decoded signal predictions that enhance BCI2000's adaptive algorithms. Several research groups have explored coupling [[neural-mass-model]]s with BCI2000's real-time pipeline to create closed-loop systems where simulated brain dynamics inform stimulation protocols, representing a direct integration point between the two platforms.

## Technical Architecture

The BCI2000 core implements a protocol-based communication system where data and control signals flow between modules via standardized messages. Signal processing modules typically operate on data vectors representing spatial filters or spectral features extracted from sliding time windows of the raw data stream. The platform's data format incorporates both the raw acquired signals and processed features, enabling post-hoc analysis using tools like [[eeglab]] or [[fieldtrip]]. BCI2000's compatibility with matlab through its MatBCI2000 interface and with Python through PyBCI2000 facilitates integration with broader computational neuroscience workflows including [[neural-mass-model]] fitting and validation.

## Key Papers

The seminal publication by Schalk, McFarland, Hinterberger, Birbaumer, and Wolpaw (2004) established BCI2000 as a standard platform for BCI research, describing its architecture and demonstrating several paradigms. Prior to this, the P300 speller paradigm had been originally described by Farwell and Donchin (1988). Wolpaw et al. (2002) provided a comprehensive review of BCI research more broadly, including communication and control applications. Motor imagery-based BCI systems were pioneered by researchers including G. Pfurtscheller and colleagues at Graz University of Technology, demonstrating that users could learn to modulate sensorimotor rhythms for control purposes. The BCI2000 platform has been cited in over 2,000 peer-reviewed publications spanning EEG-based [[neuroimaging]], MEG neuroimaging, brain-stimulation, and clinical applications for stroke rehabilitation and [[epilepsy-modeling]].

## Related Software

BCI2000 occupies a niche in the electrophysiology software ecosystem distinct from but complementary to [[eeglab]] (primarily offline analysis), [[fieldtrip]] (MATLAB-based MEG/EEG analysis pipeline), and [[openvibe]] (another real-time BCI platform). For researchers interested in combining real-time BCI paradigms with whole-brain modeling, BCI2000 provides the data acquisition layer while [[the-virtual-brain]] or [[nest]] offer simulation capabilities that can be integrated through the platform's Python interfaces. The BCPy2000 project, originating from the Max Planck Institute for Biological Cybernetic in 2007, extends BCI2000 with Python-based signal processing capabilities. Additionally, BCI2000 can interface with Psychopy for stimulus presentation and offers remote interfaces for Matlab, C++, and Python integration.
