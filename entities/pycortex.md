PyCortex is a Python library for the visualization and manipulation of cortical surface data in human neuroimaging. It renders statistical maps, time series, and parcellated data directly on inflated or flattened cortical meshes, with particular emphasis on data stored in the [[cifti]] format developed by the [[human-connectome-project]]. The library targets researchers who require pixel-precise, publication-quality surface figures rather than resampled volume representations.

## Motivation and Context

Traditional volume-based neuroimaging viewers such as [[fsl]] display data in voxel space, which forces cortical surface signals to be resampled onto a three-dimensional grid. This process introduces interpolation artifacts and obscures the topological adjacency of nearby gyral regions. The advent of high-resolution resting-state studies and fine-grained [[brain-parcellation]] schemes such as the [[glasser-atlas]] created demand for tools that preserve the native two-dimensional manifold of the cortical sheet. PyCortex addresses this need by maintaining data in vertex-level surface coordinates, enabling accurate rendering across highly tessellated meshes of roughly thirty-two thousand vertices per hemisphere without loss of spatial precision. Its design philosophy centers on spatial fidelity and seamless integration with the CIFTI ecosystem, ensuring that group-level statistical results remain visually interpretable on the cortical surface.

## Technical Implementation

PyCortex ingests CIFTI files through [[nibabel]] and maps cortical data onto surface geometries generated by [[freesurfer]] or Human Connectome Project pipelines. The API exposes a declarative figure specification: users define an overlay that selects the data layer, a basemap that supplies the anatomical reference mesh, and display parameters including colormap, threshold, and transparency. Renderings can be exported as static SVG or PNG images, or inspected interactively via an embedded WebGL viewer that supports rotation, zoom, and vertex-level value queries. The library also handles both volumetric CIFTI components, which contain subcortical voxels, and metric CIFTI components restricted to the cortical sheet, applying the appropriate rendering strategy for each domain. Additional utilities map data between alternative surface resolutions, for example from the fsaverage to the fsLR tessellation, which supports cross-study comparisons across different preprocessing pipelines.

## Relationship to TVB

[[the-virtual-brain]] is a simulator of primate brain network dynamics [[raw/papers/sanz-leon-2013.md|Sanz Leon et al., 2013]] that integrates computational modeling with multimodal neuroimaging [[raw/papers/ritter-2013.md|Ritter et al., 2013]], producing [[bold-signal]] predictions, [[effective-connectivity]] estimates, and regional time series. These outputs can be exported as CIFTI files and visualized in PyCortex to place simulated activity patterns in anatomical context. While [[tvb-webui]] provides built-in surface rendering for quick inspection during model construction, PyCortex offers superior handling of multiple [[brain-parcellation]] schemes and tighter integration with the broader HCP visualization conventions, including the Workbench color palettes. Researchers therefore often use TVB for generative modeling and then turn to PyCortex for final figure production and detailed hypothesis exploration on the cortical sheet. In addition, structural connectivity matrices derived from [[diffusion-imaging]] pipelines such as [[mrtrix3]] or [[dipy]] can be projected onto cortical surfaces in PyCortex, providing anatomical grounding for the connectivity constraints that drive [[whole-brain-modeling]] simulations in TVB.

## Position in the Visualization Ecosystem

PyCortex occupies a specialized niche rather than displacing general-purpose viewers. For volume-based inspection, [[fsl]] remains the standard; for alternative surface exploration, [[pysurfer]] provides comparable vertex-level rendering with a different API philosophy; for atlas-based dimensionality reduction and clustering visualization, [[brainspace]] offers complementary functionality. [[connectome-workbench]] serves as the official HCP viewer and excels at native CIFTI interaction, but PyCortex distinguishes itself through programmatic Python-level control and superior static figure generation. This combination makes it particularly valuable for consortium-scale projects such as the Human Connectome Project and UK Biobank, where reproducible, publication-ready surface maps are required. The library excels when working with CIFTI-native data and when researchers need to display high-resolution resting-state [[functional-connectivity]] patterns, fine-grained parcellations such as Glasser or [[schaefer]], and statistical contrasts derived from task-based paradigms.
