PySurfer is a Python library for visualization and analysis of cortical surface data generated by [[freesurfer]]. It provides a programmatic interface for rendering brain surfaces, overlaying statistical maps, displaying ROI (region of interest) labels, and creating publication-quality figures from FreeSurfer anatomical and functional outputs. The library extends [[mayavi]]'s powerful 3D rendering engine (built on vtk) with a high-level Python interface, enabling reproducible, scriptable visualizations that would otherwise require manual interaction with FreeSurfer's GUI tools [[source-separation]].

## Motivation and Context

FreeSurfer is the de facto standard for automated cortical reconstruction in neuroimaging, producing detailed surfaces, parcellations, and morphological measures from MR images. However, visualization in FreeSurfer traditionally relies

the interactive GUI [[freeview]], which is poorly suited for batch processing, reproducible pipelines, or integration with analysis workflows [[source-separation]]. Researchers analyzing large datasets—such as [[hcp-dataset]] releases or [[uk-biobank]] imaging cohorts—need to generate consistent visualizations across hundreds or thousands of subjects without manual intervention.

PySurfer addresses this gap by exposing FreeSurfer's surface visualization capabilities through Python, enabling automated figure generation, batch processing of group analyses, and integration with the broader Python neuroimaging ecosystem including Nilearn, Mne Python, and [[pybids]] [[source-separation]]. This programmatic approach is essential for reproducible research workflows in [[computational-neuroscience]] and [[connectomics]] studies where visualizing many surfaces consistently is necessary.

## Key Features

PySurfer provides several core visualization capabilities that map directly to common neuroimaging analysis workflows. The primary feature is the ability to plot data on inflated or flattened cortical surfaces, with control over lighting, colormaps, and annotation labels. Researchers can overlay statistical maps (e.g., from group-based [[fmri]] analyses), display ROI labels from [[parcellation]] schemes like the [[desikan-killiany-atlas]] or [[glasser-atlas]], and save outputs in vector or raster formats suitable for publication.

The library supports multiple views simultaneously, enabling side-by-side comparisons of hemispheres or different analysis outcomes. Curvature information from FreeSurfer can be displayed as a background to provide anatomical reference, and users can configure color schemes, transparency, and label visibility [[source-separation]]. PySurfer also handles [[connectivity]] visualizations, displaying functional or structural connectivity matrices on the cortical surface through edge visualization capabilities.

## Relationship to TVB

PySurfer serves as a complementary visualization tool for [[the-virtual-brain]] (TVB) workflows that involve surface-based brain models. TVB supports cortical surface simulations where neural activity propagates across regions defined by [[structural-connectivity]] matrices derived from [[diffusion-imaging]] data. Researchers using TVB to simulate [[whole-brain-modeling]] scenarios—such as [[epilepsy-modeling]] or [[brain-stimulation]] experiments—often need to visualize the resulting timeseries or spatial patterns on anatomically realistic cortical surfaces. PySurfer provides the visualization layer for these outputs, bridging TVB's simulation results with FreeSurfer-derived cortical geometry.

This integration is particularly valuable in [[personalized-brain-modeling]], where TVB instances are fitted to individual subject data. PySurfer can visualize individual cortical surfaces, parcellations, and simulation outcomes for quality control and result interpretation.

## Related Software

PySurfer occupies a specific niche in the neuroimaging visualization landscape alongside several other tools. Nilearn provides surface visualization capabilities but focuses more on volume-based analyses and statistical inference [[source-separation]]. Mne Python offers complementary visualization for EEG and MEG data, including source estimation displayed on cortical surfaces. [[connectome-workbench]] (wb_command) provides command-line visualization for CIFTI format data popular in the [[human-connectome-project]], while Pycortex offers a Python interface for WebGL-based interactive brain visualizations. For pure surface-based statistics, [[surfstat]] provides MATLAB-based tools that parallel some PySurfer functionality in that language.

The broader visualization ecosystem also includes Fsl's Fsleyes, [[brainnet-viewer]], and [[brainvoyager]] for volume-based visualizations, though these lack the tight integration with FreeSurfer outputs that PySurfer provides. Together, these tools form the visualization backbone for modern [[neuroimaging]] research in [[connectome]]-based [[whole-brain-modeling]] [[source-separation]].

## Key Papers

While PySurfer is a software tool rather than a research publication, it is used extensively in neuroimaging research. The library is cited in studies employing surface-based analysis of fMRI, MEG, and connectivity data. Notable applications include cortical structural and functional coupling studies during development [[source-separation]], investigations of brain-gastric phase synchronization [[source-separation]], and analyses of default-mode network organization across primates [[source-separation]]. The library has been used in work published in journals including *Translational Psychiatry*, *Human Brain Mapping*, *NeuroImage*, and *Cell Reports* [[source-separation]].
