## Overview

**BrainSMASH** (Brain Surrogate Maps with Autocorrelated Spatial Heteroscedasticity) is a Python toolbox designed to generate spatially constrained null models for brain surface maps. Developed to address a fundamental challenge in [[connectomics]] — determining whether observed differences in [[connectivity]] between regions, groups, or experimental conditions are statistically significant or merely arise from the inherent spatial autocorrelation in [[brain-network]] data — BrainSMASH provides surrogate map generation algorithms that preserve the spatial autocorrelation structure of empirical brain networks while allowing edge weights to vary under specified constraints. The toolbox is particularly valuable for vertex-wise and parcel-wise analyses of cortical and subcortical data, where spatial autocorrelation can produce inflated false positive rates in standard statistical tests.

## Motivation and Context

Brain connectivity data exhibits pronounced spatial autocorrelation: nearby brain regions tend to have similar connectivity patterns due to both anatomical proximity and shared cytoarchitectural constraints. This spatial structure creates a major methodological challenge for statistical inference — standard tests that assume independent observations often produce inflated false positive rates when applied to brain connectivity data, leading to potentially misleading conclusions about group differences or experimental effects. This problem is especially acute in [[whole-brain]] analyses where thousands of vertices or parcels are tested simultaneously.

BrainSMASH was developed to address this issue by generating surrogate brain networks that preserve the spatial autocorrelation structure of the original data, thereby providing appropriate null distributions for statistical inference. The toolbox implements algorithms that shuffle connectivity values while maintaining spatial constraints, producing null models that reflect the empirical spatial statistics while eliminating true connectivity structure. This approach represents a methodological advance over simpler permutation tests that shuffle labels but fail to account for spatial autocorrelation, and over earlier null models that ignored heteroscedasticity (non-constant variance) in brain connectivity data.

## Key Features

BrainSMASH provides several core functionalities for connectivity analysis. First, the toolbox implements **surrogate map generation** using spatially constrained shuffling algorithms. These surrogates preserve the empirical distribution of connection weights while redistributing edges in a way that respects the spatial autocorrelation structure and heteroscedasticity. Users can specify whether to preserve degree distributions, weight distributions, or other network properties during the shuffling process.

Second, BrainSMASH includes **statistical comparison tools** for testing differences between connectivity patterns. The toolbox implements both vertex-wise and parcel-wise comparison methods, allowing researchers to test for group differences, developmental effects, or condition-specific changes at multiple spatial scales. The null models generated by BrainSMASH serve as the reference distribution against which empirical differences are assessed, providing properly calibrated significance values.

Third, the toolbox supports **edge-wise and vertex-wise** analyses, enabling flexible statistical inference depending on the research question. For parcel-based analyses, BrainSMASH works with parcellated connectivity matrices, while vertex-wise analysis operates on dense connectivity data. The toolbox is compatible with standard neuroimaging file formats (GIFTI, [[cifti]]) and integrates with other Python-based neuroimaging toolboxes.

Fourth, BrainSMASH provides **parallel processing capabilities** to accelerate the computationally intensive surrogate generation process. Generating thousands of surrogate maps for robust statistical inference can be computationally expensive, and the toolbox's parallel implementation makes this practical on modern multi-core processors. The Python implementation supports easy integration into larger analysis pipelines.

## Relationship to TVB

BrainSMASH operates in a complementary space to [[the-virtual-brain]] (TVB). While TVB is primarily a forward modeling framework for simulating whole-brain dynamics using [[neural-mass-model]]s and [[connectome]]-based networks, BrainSMASH provides the statistical infrastructure for empirically analyzing real brain connectivity data. Researchers using TVB often validate their simulated dynamics against empirical [[functional-connectivity]] patterns, and BrainSMASH can serve as the analytical tool for comparing simulated and empirical connectivity, or for characterizing group differences in empirical datasets used to parameterize TVB models.

The two tools address different stages of the [[whole-brain-modeling]] workflow: TVB handles the biophysically grounded simulation of brain dynamics, while BrainSMASH provides the statistical comparison framework for connectivity analysis. In practice, a researcher might use TVB to simulate brain activity under certain parameter regimes, then use BrainSMASH to compare the resulting functional connectivity patterns against empirical human [[neuroimaging]] data from tools like [[freesurfer]] or [[fsl]]. BrainSMASH is also relevant for TVB researchers seeking to characterize the statistical significance of empirical connectivity differences that inform model parametrization.

## Relationship to Other Tools

BrainSMASH occupies a niche distinct from other connectivity-related toolboxes. The [[brain-connectivity-toolbox]] (BCT) provides general network analysis metrics and manipulation functions, but lacks the spatially constrained null model generation that BrainSMASH specializes in. Similarly, [[bctpy]] (the Python version of BCT) offers network measures but not the statistical inference framework that BrainSMASH provides.

For [[resting-state]] [[functional-connectivity]] analysis, tools like [[conn]] and [[nilearn]] provide preprocessing and basic connectivity estimation, but the generation of spatially appropriate null models for statistical testing typically requires BrainSMASH or similar specialized tools. The toolbox integrates well with Python-based preprocessing pipelines like [[fmriprep]] and can operate on output from [[dti]] tractography pipelines that produce [[structural-connectivity]] matrices.

## Key Papers and Development

BrainSMASH was introduced by Burt and colleagues (2020) to address the specific statistical challenges of comparing connectivity data across brain regions, groups, and experimental conditions. The development of spatially constrained null models that account for both autocorrelation and heteroscedasticity represents a methodological advance over earlier permutation-based approaches. The toolbox has been widely adopted in studies of [[developmental-trajectories]], clinical comparisons, and individual differences in brain connectivity, where distinguishing true connectivity differences from spatial artifacts is critical.

The software is maintained as an open-source Python package (available at https://github.com/brentmc/brainsmash), with ongoing development supporting new features and integration with other tools. The current version is v0.4.x, representing a mature and well-documented tool suitable for production research workflows. Users are encouraged to consult the documentation and the original methodological literature for proper implementation of the null model approach.
