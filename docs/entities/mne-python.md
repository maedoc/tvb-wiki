**MNE-Python** is an open-source Python library for analyzing magnetoencephalography ([[meg]]) and electroencephalography ([[eeg]]) data. [[raw/papers/gramfort-2013.md|Gramfort et al. (2013)]] describe it as providing comprehensive functionality for importing, preprocessing, analyzing, and visualizing electrophysiological recordings, with support for multiple acquisition file formats. The library enables [[source-localization]], time-frequency analysis, and [[connectivity]] estimation within a single integrated environment, making it a cornerstone tool for translating sensor-level recordings into anatomically interpretable source-space estimates.

## Motivation and Context

The analysis of MEG and EEG data presents methodological challenges distinct from those of functional magnetic resonance imaging ([[fmri]]): while electrophysiological modalities capture millisecond-level neural dynamics, they suffer from the ill-posed inverse problem of reconstructing intracranial sources from scalp recordings. [[raw/papers/gramfort-2013.md|Gramfort et al. (2013)]] document that MNE-Python addresses this gap by offering source localization and connectivity estimation within a unified open-source environment, reducing reliance on closed-source tools that constrained methodological innovation and [[reproducibility]]. [[raw/papers/semanticscholar-9e42d6a25d21.md|Lodema et al. (2026)]] note that although MNE-Python is powerful, its command-line interface can pose a barrier for researchers without programming experience, motivating wrapper applications such as EEG-Pype that expose its functions through graphical interfaces. [[raw/papers/semanticscholar-5a69b770faf9.md|Shabestari et al. (2025)]] demonstrate that the ecosystem also extends to real-time brain-computer interface applications, where efficient neural feature extraction from streaming MEG/EEG is essential for enhancing neurofeedback efficacy.

## Key Features

MNE-Python implements a complete analysis pipeline from raw sensor data to source estimates. [[raw/papers/gramfort-2013.md|Gramfort et al. (2013)]] document its support for multiple acquisition formats, including BDF through the `mne.io.read_raw_bdf()` function, which automatically parses 24-bit integer data, converts it to float32, and extracts trigger events from status channels for downstream epoching. [[raw/papers/semanticscholar-9e42d6a25d21.md|Lodema et al. (2026)]] detail how the library handles frequency band filtering, independent component analysis for artifact removal, and atlas-based beamforming for source-level analysis, alongside interactive plots for manual quality control of bad channels and epochs. The connectivity module implements spectral and [[functional-connectivity]] metrics, and configuration saving enables batch reruns with improved documentation. [[raw/papers/semanticscholar-5a69b770faf9.md|Shabestari et al. (2025)]] further show that the ecosystem extends to real-time applications through MNE-RT, a specialized package that extracts univariate metrics such as frequency band power and entropy alongside bivariate connectivity measures from streaming MEG/EEG signals.

The MNE-Python ecosystem has grown beyond the core library to address diverse user needs. [[raw/papers/semanticscholar-9e42d6a25d21.md|Lodema et al. (2026)]] present EEG-Pype, an open-source graphical interface built on MNE-Python that targets preprocessing of [[resting-state]] EEG data, guiding clinicians and non-programmers through filtering, ICA, and atlas-based beamforming while saving logs for reproducibility. [[raw/papers/semanticscholar-5a69b770faf9.md|Shabestari et al. (2025)]] introduce MNE-RT for real-time neural feature extraction, compatible with various recording systems and designed to enhance neurofeedback efficacy in brain-computer interface systems. These extensions illustrate how the core library serves as a computational backend for specialized interfaces ranging from standardized batch pipelines to online signal processing.

## Relationship to TVB

MNE-Python provides source-space electrophysiology and connectivity estimates that serve as empirical anchors for whole-brain modeling workflows. [[raw/papers/gramfort-2013.md|Gramfort et al. (2013)]] implement source localization and time-frequency analysis that transform sensor-level MEG/EEG into anatomically interpretable signals, while their connectivity estimation tools yield network metrics from empirical recordings. [[raw/papers/semanticscholar-9e42d6a25d21.md|Lodema et al. (2026)]] demonstrate that atlas-based beamforming and functional connectivity analysis in MNE-Python produce regional time courses and adjacency structures compatible with the network representations used in connectome-based simulation. [[raw/papers/semanticscholar-5a69b770faf9.md|Shabestari et al. (2025)]] extend this utility to real-time settings, where streaming connectivity extraction from MEG/EEG supports closed-loop neurofeedback systems that can validate simulated dynamics against empirical brain states. These capabilities make MNE-Python a natural preprocessing and validation partner for platforms such as [[the-virtual-brain]] that simulate large-scale [[neural-mass-models|neural mass dynamics]].
