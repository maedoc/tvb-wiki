## Abstract

Edge AI and IoT applications are growing quickly which shows us our systems must work both fast and use little energy to make decisions on limited resources. Deep learning methods deliver high accuracy output yet these models consume excessive power and require substantial processing resources making them unfit for resource-starved applications. Neuromorphic computing presents a better option by letting Spiking Neural Networks duplicate the brain's natural eventdriven processing style. This project develops a Spiking Neural Network framework as an efficient solution to enhance scalability, adaptation and energy use in neuromorphic systems. The system relies on the biological learning principles STDP, Hebbian learning, and reinforcement learning to automatically update connection weights as it detects spatiotemporal patterns in real-time. Due to its pattern finding power and low energy usage this model serves practical applications in medical and industrial environments. Here tested the model using samples from the MNIST handwritten digit set by applying spike coding methods that used both rate changes and timing patterns. The team used Python library tools and neuromorphic simulator programs to build and test their design. Experimental findings show that the new neural network system gives $\mathbf{9 6. 8 \%}$ accuracy. The system's performance in pattern recognition tasks surpasses competitors like Convolutional Neural Networks and Support Vector Machines. The system works fast while using little power which matches what real-time IoT and Edge AI systems require. This research delivers an energy-saving neuromorphic system that excels at deep learning while working with limited power in edge devices ready for embedded smart technologies and automation applications.
