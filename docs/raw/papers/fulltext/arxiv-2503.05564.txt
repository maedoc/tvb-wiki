     Fig. 2. Pairwise phase distributions across the classes of inputs.                                  VI. C ONCLUSION
                                                                                 In this work, parameters of a Jansen and Rit neural mass
                                                                              model were optimized using a genetic algorithm to maximize
                                                                              the model’s response to distinct classes of inputs to explore
                                                                              computational models of neural encoding. The model that
                                                                              maximized responses encoded the different inputs as phase-
                                                                              shifted oscillations, which were decoded into oscillatory power
                                                                              by peak-aligning excitatory inputs. This provides a biolog-
                                                                              ically inspired computational model for simple encoding-
                                                                              decoding in a neural circuit.
