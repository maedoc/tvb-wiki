                                                  ❚ ABSTRACT
                                                  Objective: This study evaluated the association between cognitive function and quantitative
                                                  magnetic resonance imaging analyses, including brain volume, white matter hyperintensity
                                                  volume, and diffusivity metrics. Methods: This retrospective analysis included 504 older adults
                                                  from São Paulo, Brazil, who underwent 3T magnetic resonance imaging scans. Image analysis was
                                                  performed using the FMRIB Software Library (FSL), with peak width of mean diffusivity assessed
                                                  via a public script. FLAIR signal changes were quantified using the Lesion Segmentation Tool
                                                  and Fazekas scale. Cognitive performance was assessed using MMSE and 3MS tests. Multiple
