## Abstract

Cross-species cortical parcellation is vital for identifying conserved brain regions, yet geometric and connectivity discrepancies limit current methods. This study proposes a two-stage clustering framework for joint human-macaque cortical parcellation using multimodal connectivity features and low-rank tensor learning. We first construct vertex-based feature matrices that integrate structural connectivity and pathway correlation to achieve a unified cross-species representation. Super-vertex clustering generates contiguous regions via a hybrid distance metric that combines geometric and feature similarities, which are refined into homologous parcels via low-rank tensor learning. Results across species indicate our method effectively identifies homologous cortical regions with improved alignment and cross-species consistency. Code is available at https://github.com/NIMGroup/Cross-species-cortex-parcellation.
