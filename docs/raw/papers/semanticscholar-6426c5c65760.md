## Abstract

Autism Spectrum Disorder (ASD) is a neurodevelopmental condition characterized by impairments in communication, behavior, and social interaction. Structural magnetic resonance imaging (sMRI) provides important insights into anatomical variations associated with ASD. This study introduces a hybrid deep learning framework that integrates voxel-based morphometry (VBM) features with spatially focused features obtained from Attention U-Net segmentation. VBM captures global volumetric information, while Attention U-Net emphasizes region-specific gray matter structures. The combined feature set is used to train a Multi-Layer Perceptron (MLP) classifier to distinguish individuals with ASD from typically developing controls. Evaluation on the ABIDE dataset demonstrates that the proposed method achieves an accuracy of 88.6%. The novelty of this framework lies in fusing global morphometric biomarkers with region-specific deep features, thereby enhancing both classification accuracy and interpretability for ASD neuroimaging analysis.
