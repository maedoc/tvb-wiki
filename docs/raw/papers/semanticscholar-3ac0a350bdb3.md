## Abstract

Electroencephalography (EEG) source localization is an ill-posed inverse problem, traditionally addressed with either parametric dipole fitting or distributed inverse algorithms constrained by priors. Recently, data-driven methods have emerged, but they often rely on purely simulation-based training data without explicitly enforcing the physics of EEG signal propagation. In this work, we present a finite element model of the human head using a four-layer spherical volume conductor. This forward model, implemented in COMSOL Multiphysics, provides accurate simulations of scalp potentials generated by current dipole sources in the brain. We demonstrate that our model's output agrees with the analytical solution for the classical foursphere head model, ensuring its validity as a ground truth generator. The synthetic EEG data produced by this model can be used to train and validate a novel physics-informed neural network (PINN) for EEG source localization. This represents a first step towards integrating physical law constraints directly into deep learning for EEG source imaging.
