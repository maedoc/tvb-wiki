## Abstract

This paper presents an approach to training a spiking neural network based on the GRAS (GPU Reflex Arc Simulator) neural simulator, using spike-timing-dependent plasticity (STDP) and data from pressure sensors embedded in wearable insoles. We develop an algorithm that converts sensor time series into spike frequency for the input layer. Prior to encoding, signals are normalized and smoothed to reduce noise and improve spike coding. The resulting network configuration is compared with a reference configuration developed in the Laboratory of Neuromorphic Computing and Neurosimulations, and its effectiveness is assessed using several metrics. In addition, we simulate a walking pattern generated by a central pattern generator, using self-learning STDP driven by pressure-sensor input frequency coding.
