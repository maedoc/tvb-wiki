## Overview

OpenCortex is a Python-based software framework for building, visualizing, and simulating cortical neural network models in [[neuroml]] format. Developed primarily by Padraig Gleeson starting in 2015, the platform was designed as part of the [[open-source-brain]] ecosystem to provide researchers with standardized tools for creating large-scale cortical microcircuit models that could be shared across different [[spiking-neural-networks]] simulators. The framework enables users to define cell populations with custom morphologies in three-dimensional space, specify synaptic connections with various receptor types (AMPA, NMDA, GABA), and generate network descriptions that can be exported for simulation in multiple backends including [[neuron]] and NEST.

## Motivation and Context

The development of OpenCortex emerged from a broader effort in [[computational-neuroscience]] to address the challenge of model reproducibility and interoperability. During the mid-2010s, the field faced a fragmented landscape where researchers developed cortical network models using custom code or simulator-specific formats, making it difficult to reproduce, compare, or extend published work. NeuroML had emerged as a candidate standard for describing neuronal models in a simulator-independent format, but the tooling for building large, structured networks remained limited. OpenCortex was conceived to fill this gap by providing a Python library that could programmatically generate complete NeuroML network descriptions, complete with detailed connectivity, cell morphologies, and stimulation protocols.

The framework was particularly motivated by the growing interest in laminar cortical circuits and the need to incorporate detailed anatomical connectivity data from experimental studies. As the Human Brain Project and related initiatives pushed toward large-scale brain modeling, tools like OpenCortex represented an attempt to bridge the gap between single-neuron biophysics and [[whole-brain modeling]] approaches by providing a standardized way to construct cortical microcircuits that could later be embedded in larger network architectures.

## Key Features

OpenCortex provides a comprehensive API for constructing cortical networks through Python scripts. The core functionality centers on several fundamental operations: creating networks with specified random seeds and temperatures (critical for reproducibility), defining cell populations in either rectangular 3D volumes or through layered structures that approximate cortical laminae, and populating these regions with individual neurons using either built-in prototype cell models or custom NeuroML cell definitions. The framework includes standard cell prototypes based on [[izhikevich]] neuron models and single-compartment [[hodgkin-huxley-model]] representations, though users can also import their own morphologically detailed cells.

The connectivity system in OpenCortex supports both probabilistic projections, where connections between pre- and postsynaptic cells are established according to a specified probability, and targeted projections that allow fine-grained control over which cellular compartments (soma, dendrites, axon) participate in the connection. The targeting modes include convergent connectivity (from multiple presynaptic cells to a single postsynaptic target) and divergent connectivity (from a single presynaptic cell to multiple postsynaptic targets). Synaptic mechanisms supported include exponential one- and two-synapse models with configurable time constants and reversal potentials, as well as gap junction connections for electrical coupling.

For input generation, the framework provides tools for adding current injections (pulse generators), Poisson firing synaptic inputs, and transient inputs with specified onset, duration, and rate. These inputs can be applied either to all cells in a population or to specific subsets, and can be targeted to particular segment groups on morphologically detailed cells. The simulation backend uses [[pynn]] and LEMS (Low-level Evolutionary Mechanism for Spiking neural networks) to generate executable simulation descriptions, which can then be run on various supported simulator platforms.

## Relationship to TVB and Other Simulators

While OpenCortex is primarily focused on constructing detailed cortical microcircuits at the level of individual neurons and synapses, its relationship to [[the-virtual-brain]] (TVB) reflects the broader integration between detailed circuit modeling and [[whole-brain modeling]] approaches. The networks generated by OpenCortex can serve as biologically realistic cortical regions that TVB's Connectome-based modeling framework can incorporate as local dynamics. This is particularly relevant for TVB's ability to connect multiple brain regions through structural [[connectivity]] data derived from [[diffusion-imaging]] and tractography, where individual regions can be equipped with biophysically realistic neural mass or spiking network models.

OpenCortex also relates to other specialized neural simulation environments. Unlike the [[brian]] or [[brian2]] frameworks which emphasize ease of use and rapid prototyping, OpenCortex prioritizes model sharing and interoperability through standardization. Compared to [[nest]], which focuses on efficient large-scale simulations, OpenCortex serves more as a model construction tool that exports descriptions for simulation elsewhere. The framework overlaps conceptually with [[annarchy]] and [[netpyne]] in its focus on structured cortical networks, but distinguishes itself through its commitment to the NeuroML standard.

## Limitations and Legacy

OpenCortex has been in development status since its initial release, and the maintainers have noted that much of its core functionality has been superseded by NeuroMLlite, a more streamlined successor project that simplifies the generation of NeuroML network descriptions. As of recent updates (2024-2025), the GitHub repository shows continued maintenance activity though with limited new feature development. Users interested in modern NeuroML-based network construction may find NeuroMLlite more actively maintained, though OpenCortex remains useful for existing models and for specific use cases involving detailed laminar cortical circuits.

Despite its limitations, OpenCortex contributed to the [[computational-neuroscience]] ecosystem by demonstrating the feasibility of programmatic network construction using standardized formats. Its emphasis on [[neuroml]] compatibility helped advance the adoption of model description standards, and some of its design principles influenced subsequent tools in the Open Source Brain ecosystem.
