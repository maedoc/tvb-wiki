BIDS (Brain Imaging Data Structure) is a standardized specification for organizing and sharing neuroimaging data. It defines a hierarchical file structure with standardized naming conventions, metadata schemas (in JSON sidecar files), and data formats that make neuroimaging datasets interoperable across different analysis tools and laboratories. Originally developed to address the reproducibility crisis in neuroimaging, BIDS has become the de facto community standard for sharing raw neuroimaging data, particularly for [[resting-state]] and task-based [[fmri]] studies, as well as [[neuroimaging-eeg]], [[neuroimaging-meg]], and diffusion-weighted imaging ([[dti]]).

The motivation for BIDS emerged from a recognition that neuroimaging data was being stored in highly idiosyncratic ways across different labs—a problem that made data sharing, reuse, and automated analysis extremely difficult. Before BIDS, each research group had its own conventions for folder organization, file naming, and metadata storage, requiring custom parsing scripts for each dataset. This fragmentation hindered large-scale collaborative analyses and made it difficult to build automated preprocessing pipelines. The BIDS specification solves this by prescribing exactly how data should be organized: subject folders contain session folders, which contain modality-specific subdirectories (anat, func, dwi, eeg, meg), and each file follows a precise naming pattern that encodes information about the subject, session, task, and acquisition type. The accompanying JSON sidecar files store essential metadata such as repetition time, echo time, and slice timing, eliminating the need to infer these parameters from DICOM headers or private conventions.

From a technical standpoint, BIDS specifies data formats that are widely supported in the neuroimaging ecosystem. For volumetric data, NIfTI files with associated JSON sidecars are the standard, while MEG and EEG data are stored in BrainVision or FIF formats. Diffusion imaging data follows a specific organization with bvecs and bvals stored separately. The specification also defines how to represent derivatives—preprocessed data, statistical maps, and region-of-interest timeseries—which enables standardized comparison across studies. Crucially, BIDS includes a formal validation tool (the BIDS Validator) that can check whether a dataset conforms to the specification, catching organizational errors before they propagate through analysis pipelines.

The relationship between BIDS and [[the-virtual-brain]] (TVB) is indirect but significant in the broader whole-brain modeling workflow. TVB requires empirical structural and functional connectivity data as input, typically derived from [[diffusion-imaging]] (for tractography-based structural connectivity) and [[resting-state-fmri]] (for functional connectivity matrices). Many modern datasets that feed into TVB pipelines are now distributed in BIDS format, including the [[human-connectome-project]] (HCP), [[uk-biobank]], and various clinical cohort datasets. Tools like [[pybids]] allow programmatic access to BIDS datasets, enabling automated extraction of neuroimaging timeseries for connectivity analysis. The TVB ecosystem has developed adapters and importers that can consume BIDS-organized data, making it easier to go from raw imaging data to personalized whole-brain models. Additionally, the BIDS Apps specification defines containerized analysis pipelines that can run directly on BIDS datasets, which aligns with TVB's emphasis on reproducible, automated workflows.

Several related tools and concepts extend the BIDS ecosystem. [[nipype]] provides Python interfaces for neuroimaging tools and has native support for working with BIDS datasets. BIDS Apps are containerized neuroimaging applications that run standardized analysis pipelines on BIDS data. The BIDS Derivatives extension allows processed data to remain in BIDS-compliant format, enabling chains of analyses where each step's output remains interoperable. For researchers working with TVB, understanding BIDS is valuable because it represents the standard input format for many large-scale neuroimaging datasets that may serve as sources for connectome extraction. Personalization of whole-brain models depends on having well-organized imaging data, and BIDS provides that organizational foundation.

Despite its widespread adoption, BIDS continues to evolve. Extensions (known as "BIDS Appendices") have been proposed for additional modalities and analysis types, including PET, physiology, and behavioral data. The community actively maintains the specification through the BIDS Governance committee, and adoption continues to grow—major neuroimaging databases including [[openneuro]], the UK Biobank, and the HCP either distribute data in BIDS format or provide BIDS converters. For computational neuroscience workflows involving whole-brain modeling, BIDS serves as the data foundation that enables reproducible pipeline development from raw imaging to network model parameters.

The BIDS specification has proven particularly valuable for [[resting-state-fmri]] analyses that feed into [[functional-connectivity]] studies and ultimately into whole-brain connectivity matrices used by TVB. Researchers studying [[brain-dynamics]] through [[resting-state]] fluctuations can share datasets in BIDS format with confidence that other labs will be able to process the data using their preferred tools. This interoperability extends to [[structural-connectivity]] analyses derived from diffusion imaging, where BIDS-compliant datasets enable consistent tractography processing across sites. The standardization also facilitates meta-analyses across [[resting-state]] studies and supports the integration of data from multiple modalities—a key capability for building comprehensive models of [[brain-network]] organization.
