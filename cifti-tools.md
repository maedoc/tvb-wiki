# CIFTI Tools

## Overview

CIFTI tools refer to software utilities for working with the CIFTI (Connectivity Informatics Technology Initiative) file format, a specialized neuroimaging data format designed to represent brain-wide connectivity data efficiently. CIFTI was developed by the Human Connectome Project to address the limitations of traditional NIfTI formats when storing dense, high-resolution connectivity matrices from functional magnetic resonance imaging (fMRI) data. The format represents brain data as "grayordinates" — a hybrid representation combining surface vertices (on the cortical mantle) with volumetric voxels (in subcortical structures), enabling unified storage of surface-based and volume-based neuroimaging data.

## Motivation and Context

The development of CIFTI emerged from a fundamental challenge in connectivity neuroimaging: existing formats like NIfTI were optimized for volumetric data but struggled to represent the dense connectivity matrices generated by modern whole-brain fMRI analyses. When working at the resolution of modern HCP-style acquisitions, traditional approaches either required massive full-volume matrices (creating files of hundreds of gigabytes) or required arbitrary downsampling that discarded meaningful information.

The Human Connectome Project addressed this by introducing the CIFTI format in conjunction with its "Q1-Q6" and "1200 Subjects" data releases, which explicitly separates brain data into surface-based cortical representations and volumetric subcortical representations. This approach dramatically reduces storage requirements while preserving the full spatial resolution of the cortical sheet. CIFTI tools thus become essential for anyone working with HCP-style datasets, resting-state connectivity analyses, or large-scale brain network studies that require the full spatial fidelity of modern neuroimaging acquisitions.

### CIFTI-1 vs CIFTI-2 Distinction

The CIFTI format has evolved through two major versions. CIFTI-1 was introduced with the initial HCP Young Adult data release and supported dense series (dtseries), dense connectivity (dconn), dense scalar (dscalar), and dense label (dlabel) files. CIFTI-2, introduced around 2018 with the HCP "1200 Subjects" release, expanded support to include parcel series (pseries), parcel connectivity (pconn), parcel scalar (pscalar), and parcel label (plabel), enabling direct representation of parcellated data without external lookup tables. CIFTI-2 also clarified metadata specifications and improved compatibility with the GIFTI surface format.

## Key Features

### Grayordinates Representation

The core innovation of CIFTI is the grayordinates concept. Rather than representing the entire brain as isotropic voxels, CIFTI stores cortical data as surface vertices (the gray matter ribbon visualized on the inflated cortical sheet) and subcortical data as targeted volumetric regions. This hybrid approach captures the sheet-like geometry of the cortex while maintaining anatomical precision in structures like the thalamus, basal ganglia, and hippocampus. The standard HCP grayordinate space comprises approximately 59,412 cortical vertices across both hemispheres (using the 32k_fs_LR mesh) combined with approximately 31,870 subcortical voxels, yielding roughly 91,282 total grayordinates.

### Dense and Parcel Representations

CIFTI supports two primary data representations: dense format (full connectivity matrices at full grayordinate resolution, stored as dconn/dtseries files) and parcel format (connectivity from each grayordinate to a set of predefined parcels, stored as pconn/pseries files). Dense format provides maximum flexibility for post-hoc parcellation or parcellation-free analyses, while parcel format enables direct representation of region-level connectivity matrices using standard atlases such as the Glasser HCP Multi-Modal Parcellation. The format includes metadata specifying both the brain structures included and the parcelation used for any region-based summaries.

### Time Series and Connectivity Matrices

CIFTI can store either time series data (4D: x, y, z, time) or connectivity matrices (2D: grayordinate by grayordinate, or grayordinate by parcel). This flexibility makes it suitable for both resting-state analyses (where time series extraction is primary) and connectivity analyses (where correlation, covariance, or coherence matrices are the output). The underlying numeric values stored in CIFTI are floating-point arrays; the specific connectivity metric (e.g., Pearson correlation, partial correlation) is computed during analysis from the stored time series rather than being a format-native feature.

## Relationship to TVB

While CIFTI tools are primarily oriented toward connectivity analysis rather than forward modeling, they are highly relevant to whole-brain modeling workflows in The Virtual Brain (TVB). TVB can import structural connectivity matrices derived from diffusion tensor imaging (DTI), and many research groups have explored using functional connectivity data — which may be stored in CIFTI format — to constrain or validate whole-brain models. The parcellation schemes used in CIFTI (e.g., the Glasser atlas, Destrieux atlas) correspond to node definitions in TVB network models, enabling direct translation between CIFTI-derived connectivity matrices and TVB simulation templates. Additionally, CIFTI's grayordinates representation provides high-resolution structural substrates that could inform more detailed TVB connectomes in future implementations.

## Key Software Tools

The following specific software packages provide CIFTI functionality:

- **Connectome Workbench**: The primary tool suite for viewing and manipulating CIFTI files, maintained by the HCP. It provides the `wb_command` command-line interface for all major operations including data extraction, format conversion, and visualization.
- **CIFTI tools (MATLAB)**: A MATLAB package maintained by the HCP providing read and write capabilities for CIFTI files.
- **ciftify**: A Python package for processing CIFTI data with integration to fMRIPrep pipelines.
- **nilearn**: Python library that can fetch and manipulate CIFTI datasets via the nibabel backend.
- **nibabel**: Python library providing low-level CIFTI reading and writing capabilities.
- **ConnectomeDB**: The HCP data repository where CIFTI-format datasets are hosted.

## Key Papers

The foundational description of CIFTI appears in the Human Connectome Project's methodology papers. Glasser et al. (2013) detailed the HCP pipeline including surface registration and the specification of grayordinate files, establishing the technical foundation. Smith et al. (2013) described the resting-state fMRI analysis approaches and the generation of CIFTI-format connectivity outputs. These papers establish not only the format definition but also the preprocessing pipelines that produce CIFTI-ready outputs from raw fMRI data.
