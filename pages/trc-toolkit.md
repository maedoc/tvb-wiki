# TRC Toolkit

## Overview

The TRC Toolkit refers to the collection of tractography, reconstruction, and connectivity tools used within the TVB ecosystem for constructing subject-specific structural connectomes from diffusion MRI (dMRI) and T1-weighted MRI data. While no single tool is formally named "TRC Toolkit," the term encompasses the preprocessing pipelines, tractography algorithms, and connectivity estimation methods that transform raw neuroimaging data into TVB-compatible structural connectivity matrices. The primary pipeline for this task is the **tvb-recon** reconstruction pipeline, which provides end-to-end processing from raw MR scans to TVB-ready connectome files[^1].

The reconstruction pipeline is essential for personalized brain modeling in TVB, as it generates the anatomical connectivity matrices that serve as the structural scaffold for whole-brain simulations. This pipeline produces region-level connectivity matrices, cortical and subcortical parcellations, and surfaces that can be directly imported into TVB for simulation.

## Key Components

### tvb-recon Pipeline

The tvb-recon pipeline is the core reconstruction tool for creating full brain network models from standard structural MR scans. Developed by The Virtual Brain team, this automated pipeline transforms multimodal MRI data into TVB-compatible files including structural connectivity matrices, region mappings, and cortical surfaces.

The pipeline requires two mandatory input modalities:
- **Diffusion-weighted imaging (DWI)**: Used for tractography and white matter tract reconstruction
- **T1-weighted MRI**: Used for cortical reconstruction, parcellation, and anatomical reference

Optional inputs include CT scans for sensor preprocessing in intracranial electrode localization.

The pipeline workflow follows these principal stages:
1. **T1 Processing**: FreeSurfer's recon-all generates cortical segmentation, parcellation, and anatomical surfaces
2. **DWI Preprocessing**: MRtrix and FSL tools perform diffusion preprocessing including bias correction and registration
3. **Tractography**: Probabilistic fiber tracking generates streamlines representing white matter pathways
4. **Connectome Generation**: Tractograms are mapped to parcellated regions to produce connectivity matrices
5. **Output Formatting**: Files are converted to TVB-compatible HDF5 format

The pipeline uses the Pegasus workflow management system to automate and coordinate these processing steps, enabling both single-subject and batch processing workflows[^1].

### Tractography Tools

The reconstruction pipeline integrates several specialized tractography tools:

**MRtrix3**: Used for diffusion signal processing, constrained spherical deconvolution (CSD), and probabilistic tractography. MRtrix provides the core fiber orientation distribution estimation and streamline generation algorithms. The pipeline typically generates 10 million streamlines, filtered down to approximately 2 million using SIFT (Spherical Informed Filtered Tractography) for anatomically constrained results.

**FSL**: Provides image registration tools (FLIRT, FNIRT) for aligning diffusion and T1 images to standard space, as well as preprocessing utilities for eddy current correction and motion correction.

**FreeSurfer**: Handles all T1 processing including cortical reconstruction (recon-all), parcellation generation, and surface creation. The pipeline can generate standard Desikan-Killiany parcellations as well as higher-resolution subdivision parcellations (e.g., 100-region or 250-region parcellations)[^1].

## Relationship to TVB

The TRC toolkit components are fundamental to TVB's personalized brain modeling approach. The structural connectivity matrices generated by these pipelines define the anatomical connectivity that constrains neural mass model dynamics in TVB simulations. This connection follows a well-established workflow:

1. **Data Acquisition**: DWI and T1 scans are collected from the subject
2. **Reconstruction**: The tvb-recon pipeline processes these through tractography and connectivity estimation
3. **TVB Import**: Generated connectivity files (connectivity.zip, region mapping, surfaces) are imported into TVB
4. **Simulation**: The connectivity matrix serves as the structural basis for simulating brain dynamics

The pipeline output includes TVB-compatible files organized in the `output/tvb` folder, ready for direct import through TVB's data import interface. These files contain the weighted connectivity matrices, tract length distributions, and region mapping necessary for personalized simulations.

The pipeline has been validated in numerous studies investigating how parcellation size and short-range connectivity affect large-scale brain network dynamics.

## Related Software

The TRC toolkit intersects with a broader ecosystem of tractography and connectomics tools:

**pyAFQ (Tractometry)**: A Python toolbox for automated fiber quantification and tractometry analysis. While pyAFQ focuses on extracting tissue properties along predefined white matter tracts, tvb-recon provides the fullbrain tractography needed for TVB connectomes. The two tools can be used complementarily: pyAFQ for detailed tract-level analysis and tvb-recon for whole-brain connectivity matrices[^3].

**TractoR**: A tractography package implemented in R, providing diffusion processing, tractography, and neighborhood tractography for automated tract segmentation. TractoR emphasizes probabilistic tractography with uncertainty estimation[^5].

**TractSeg**: A deep learning-based tool for fast and accurate white matter bundle segmentation from diffusion MRI. TractSeg can segment 70+ white matter bundles and generate tract orientation maps (TOMs) for bundle-specific tractography[^6].

**DIPY**: The Diffusion Imaging in Python library provides comprehensive diffusion MRI processing capabilities including tensor estimation, reconstruction models (DTI, CSD, QBI), and tractography algorithms. DIPY serves as a foundation for many specialized tractography tools[^3].

## Key Papers

The primary references for the TVB reconstruction pipeline are:

- **Schirner et al. (2015)**: "An automated pipeline for constructing personalized virtual brains from multimodal neuroimaging data." Neuroimage. This foundational paper describes the complete pipeline for generating TVB-compatible datasets from raw MRI data.

- **Proix et al. (2016)**: "How do parcellation size and short-range connectivity affect dynamics in large-scale brain network models?" Neuroimage. This study investigates how reconstruction parameters (parcellation resolution) influence simulated dynamics.

## Installation and Usage

### Docker Deployment

The recommended way to run the reconstruction pipeline is via Docker:

```bash
# Pull the tvb-recon docker image
docker pull thevirtualbrain/tvb-recon

# Run with data mounted
docker run -it -v /path/to/data:/home/submitter/data thevirtualbrain/tvb-recon
```

### Data Organization

Input data must be organized in a specific folder structure:

```
TVB_patients/
├── TVB1/
│   └── raw/
│       └── mri/
│           ├── t1_input.nii.gz
│           ├── dwi_raw.nii
│           ├── dwi.bvec
│           └── dwi.bval
└── TVB2/
    └── raw/
        └── mri/
            ├── t1_input.nii.gz
            ├── dwi_raw.nii
            ├── dwi.bvec
            └── dwi.bval
```

### Running the Pipeline

Within the Docker container:

```bash
# Start HTCondor
sudo condor_master

# Run pipeline for a subject
cd pegasus
python run_sequentially.py "1"
```

The pipeline generates output in the `output/tvb` folder, containing TVB-ready connectivity files.
