nxviz is a Python library for network visualization built on NetworkX and matplotlib [[cite:raw/papers/rubinov-sporns-2010]]. Developed primarily by Eric Ma, nxviz provides a set of high-level plotting functions that transform graph data into publication-quality figures. While designed as a general-purpose network visualization tool applicable to any network data, nxviz has found adoption in the neuroscience community for visualizing brain networks and connectivity data derived from neuroimaging studies [[cite:raw/papers/hagmann-2008]].

## Motivation and Context

The visualization of brain networks presents distinct challenges compared to generic network graphs. Neuroimaging-derived connectivity data typically consist of symmetric matrices representing structural or functional connections between brain regions, often with edge weights reflecting connection strengths from diffusion imaging tractography or resting-state fMRI correlations [[cite:raw/papers/smith-2013-hcp]]. Standard network visualization libraries such as NetworkX provide graph manipulation capabilities but lack specialized high-level functions adapted to the particular requirements of neuroimaging connectivity visualization, including support for node hierarchies (e.g., cortical lobes or brain parcellation schemes), circular node ordering by network membership, and matrix-based representations complementary to graph-based views.

nxviz was developed to address this gap, providing visualization primitives that map naturally onto common network data structures. The library works with any NetworkX graph object, making it compatible with output from popular neuroinformatics pipelines including the Human Connectome Project analysis tools [[cite:raw/papers/smith-2013-hcp]] and the Brain Connectivity Toolbox [[cite:raw/papers/rubinov-sporns-2010]]. As a standalone plotting library, nxviz does not have special integration points with specific tools but can be used to visualize connectivity matrices and network graphs produced by various pipelines without requiring extensive custom matplotlib coding.

## Technical Features

nxviz provides four primary visualization geometries. The **circos plot** arranges nodes in a circle and draws arcs between connected regions, with edge transparency reflecting connection strength—this geometry is particularly effective for visualizing the topological organization of large-scale brain networks such as the default mode network [[cite:raw/papers/rubinov-sporns-2010]]. The **matrix plot** displays the raw connectivity matrix as a heatmap, with optional hierarchical clustering revealing community structure in the connectivity pattern. The **arc plot** similarly uses arcs to represent edges but positions nodes linearly rather than circumferentially, facilitating comparison with traditional brain parcellation ordering. Finally, the **hive plot** organizes nodes along axes grouped by categorical node attributes, providing an alternative layout for examining network structure.

All nxviz plotting functions return matplotlib Figure and Axis objects, allowing researchers to customize titles, labels, and annotations using standard matplotlib syntax. The library supports weighted and unweighted networks, directed and undirected edges, and can incorporate node metadata such as network membership from community detection algorithms. Node and edge colors follow a consistent default palette designed for grayscale printing, while also supporting custom colormap specification.

## Relationship to TVB

nxviz serves as a complementary visualization tool for outputs generated by The Virtual Brain. TVB produces structural connectivity matrices derived from diffusion imaging data as inputs to whole-brain simulations, and generates time series and connectivity estimates as simulation outputs [[cite:raw/papers/hagmann-2008]]. While TVB includes its own built-in visualization capabilities through the web interface tvb-webui, nxviz provides additional flexibility for producing static figures for publication and for custom exploratory analysis. Researchers using TVB can export connectivity matrices and simulated time series, then use nxviz to generate circos plots showing how TVB's simulated connectivity patterns relate to the empirically observed structural connectome. The library also supports visualization of effective connectivity results from TVB's dynamic causal modeling analyses.
