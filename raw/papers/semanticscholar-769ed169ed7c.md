## Abstract

Exploring temporal activity in the brain, often performed using electroencephalography (EEG), includes data analysis, signal processing and visualization. In conventional surface EEG data analysis, the lack of a friendly user interface (UI), coding flexibility and free availability are challenges for non-IT experts. In this paper, we implemented an open-source Python-Based EEG processing wrapper framework that employs a PyQt5-based graphical user interface(GUI) extending the computation capabilities of MNE-Python. Also aimed at resource limited settings, this implementation includes preprocessing methods of re-refrencing, filtering, artifact rejection using automatic subspace reconstruction, independent component analysis, and threshold-based filtering. For signal analysis, we implemented feature extraction methods including segmention of epochs, functional connectivity analysis and quasi-stable state analysis. This software implementation can be developed for sustainable healthcare surveillance with scalable extensions to connect to existing tools and to provide easy-to-use interfaces for clinicians and healthcare researchers, and users.
