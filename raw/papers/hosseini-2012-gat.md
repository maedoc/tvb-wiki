# GAT: A Graph-Theoretical Analysis Toolbox for Analyzing Between-Group Differences in Large-Scale Structural and Functional Brain Networks

**Authors:** S. M. Hadi Hosseini, Fumiko Hoeft, Shelli R. Kesler
**Year:** 2012
**Journal:** PLoS ONE, 7(7), e40709
**DOI:** https://doi.org/10.1371/journal.pone.0040709

## Abstract

The Graph Analysis Toolbox (GAT) is a MATLAB-based software package that provides a graphical user interface for graph-theoretical analysis of structural and functional brain networks. GAT computes global and nodal network measures across a range of network densities, performs non-parametric permutation tests for between-group comparisons, and produces publication-ready visualizations. The toolbox wraps core algorithms from the Brain Connectivity Toolbox (Rubinov & Sporns, 2010).
