# CRUISE: Cortical Reconstruction Using Implicit Surface Evolution

**Authors:** Xiaoyang Han, Chen Cao, J. H. Z. Zeng, Michael W. V. Ch. T. W.
**Year:** 2004  
**Venue:** NeuroImage

## Key Contributions

- Developed CRUISE algorithm for topologically correct cortical surface extraction
- Introduced implicit surface evolution for generating spherical cortical surfaces
- Combined deformable surface models with topology control mechanisms
- Provided robust cortical segmentation even in the presence of partial volume effects

## Abstract Summary

The paper presents CRUISE (Cortical Reconstruction Using Implicit Surface Evolution), a novel algorithm for extracting cortical surfaces from MRI data. The method uses implicit surface evolution combined with a topology-preserving deformable model to generate topologically spherical cortical surfaces that accurately follow the gray matter/white matter boundary. Unlike previous methods that relied on explicit mesh manipulation, CRUISE uses level set methods to evolve the surface, automatically handling topological changes while maintaining the correct genus-zero topology required for cortical surfaces.

## Method

### Implicit Surface Evolution
The algorithm represents the cortical surface as a level set function, allowing for robust evolution without manual topology correction.

### Topology Control
A topology-preserving constraint ensures that the resulting surfaces have the correct spherical topology, eliminating the need for manual topology fixing.

### Initialization and Evolution
The method initializes with a spherical mesh and uses gradient descent to evolve toward the gray-white boundary while maintaining topological correctness.
