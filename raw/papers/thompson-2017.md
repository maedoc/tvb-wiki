# From static to temporal network theory: Applications to functional brain connectivity

**Authors:** William Hedley Thompson, Per Brantefors, Peter Fransson
**Year:** 2017
**Venue:** Network Neuroscience

## Key Contributions

- Introduces temporal network theory to network neuroscience
- Defines temporal network measures: temporal centrality, closeness, burstiness, fluctuability, volatility, reachability latency, temporal efficiency
- Applies measures to resting-state fMRI eyes-open/eyes-closed dataset
- Releases Teneto: a Python package implementing all described temporal network measures

## Abstract Summary

Network neuroscience has become established for tackling questions about the brain's functional and structural connectome. Interest is growing in examining temporal dynamics of brain network activity. Although different approaches to capturing fluctuations exist, few attempts have been made to quantify them using temporal network theory. This article presents a detailed description of temporal network theory and its measures, applies them to resting-state fMRI, and discusses interpretation in the context of the dynamic functional brain connectome. All temporal network measures and plotting functions are freely available as the Python package Teneto.

## Significance

The foundational paper introducing temporal network theory to neuroimaging and presenting the Teneto software package. Demonstrates that temporal network measures are sensitive to both between-subject and between-task differences in dynamic functional connectivity.
