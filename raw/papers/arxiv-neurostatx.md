# NeuroStatX: A Python Toolbox for Neuroscience Data Analysis

## Overview

NeuroStatX is a command-line toolbox for performing statistical analysis on neuroscience data. Developed primarily for researchers studying the relationship between brain, cognition, and behavior, the package provides focused functionality for common neuroscience analysis workflows.

## Key Features

The toolbox includes statistical analysis routines specifically designed for neuroscience data types, including neuroimaging and electrophysiology formats. It supports both group-level comparisons and individual-level analyses.
