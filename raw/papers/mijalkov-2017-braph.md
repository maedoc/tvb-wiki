# BRAPH: A Pipeline for Brain Connectivity Analysis

**Authors:** Mijalkov et al.  
**Year:** 2017  
**Venue:** Frontiers in Neuroinformatics

## Key Contributions

- Introduction of BRAPH as an open-source toolbox for brain connectivity analysis
- Pipeline for analyzing structural and functional brain networks
- Support for multimodal neuroimaging data including fMRI, MRI, EEG, and PET
- Graph theory based analysis of brain connectivity

## Abstract Summary

BRAPH (Brain Analysis of GRaphs) is an open-source MATLAB toolbox designed for the analysis of brain connectivity data. It provides a comprehensive pipeline for constructing, analyzing, and visualizing brain networks derived from neuroimaging data, supporting multiple modalities including functional MRI (fMRI), structural MRI (MRI), electroencephalography (EEG), and positron emission tomography (PET).

## Significance

BRAPH has become an important tool in the connectomics field, providing researchers with a standardized pipeline for brain network analysis. Its support for multiple neuroimaging modalities makes it versatile for both structural and functional connectivity studies.
