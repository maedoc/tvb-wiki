# GRETNA: a graph theoretical network analysis toolbox for MATLAB

**Authors**: Wang, J., Wang, X., Xia, M., Liao, X., Evans, A., & He, Y. (2015)
**Journal**: Journal of Neuroscience Methods
**Volume**: 252
**Pages**: 130-138
**DOI**: https://doi.org/10.1016/j.jneumeth.2015.04.016
**Full text**: https://doi.org/10.1016/j.jneumeth.2015.04.016

## Summary

This paper introduces GRETNA (Graph Theoretical Network Analysis), a MATLAB-based toolbox for graph-theoretic analysis of brain connectivity networks derived from neuroimaging data. The toolbox provides comprehensive implementations of network metrics for both global and regional analysis, supporting various parcellation schemes, thresholding strategies, and network construction pipelines. GRETNA addresses the need for standardized, reproducible network analysis in the connectomics field.

## Key Contributions

- MATLAB toolbox for brain network analysis using graph theory
- Comprehensive implementation of global and regional network metrics
- Support for multiple parcellation schemes and thresholding approaches
- Graphical user interface and command-line functionality
- Built-in statistical testing for group comparisons
