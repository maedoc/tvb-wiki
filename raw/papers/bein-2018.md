# pyedflib: Python library for reading and writing EDF/BDF files

**Author**: B. Bein (2018)
**Journal**: Journal of Open Source Software
**DOI**: https://doi.org/10.21105/joss.00899
**Repository**: https://github.com/holgern/pyedflib

pyedflib is a Python library that provides read and write access to EDF (European Data Format) and BDF (BioSemi Data Format) files. It is based on the EDFlib C library by Teunus van Beelen and provides a Pythonic interface for handling these neurophysiological data formats.

## Features

- Read and write EDF and BDF files (including EDF+ variant)
- Support for 16-bit EDF and 24-bit BDF formats
- Header manipulation (channel labels, sampling rates, physical dimensions)
- Annotation support for EDF+
- Minimal dependencies (only NumPy)
- Both Python 2 and Python 3 compatibility

## BDF Support

pyedflib handles BDF files specifically by:
- Parsing the 24-bit three-byte integer encoding
- Reading the status channel for trigger/event extraction
- Supporting channel-specific gain factors
- Bidirectional conversion (can write BDF from existing data)

This library is widely used in EEG preprocessing pipelines and serves as a building block for more specialized BDF handling tools.
