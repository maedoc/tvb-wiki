# neurosift - Flatiron Institute

Browser-based NWB visualization and DANDI exploration tool developed by the Flatiron Institute's Center for Computational Mathematics.

## Repository Information

- Stars: 64
- Forks: 15
- Primary language: TypeScript
- License: Apache License 2.0
- Homepage: https://neurosift.app

## Key Capabilities

- View NWB files directly in browser
- Browse DANDI Archive datasets
- Explore OpenNeuro datasets
- NIfTI visualization support
- Local installation via pip
