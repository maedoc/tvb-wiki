# Geppetto: a reusable modular open platform for exploring neuroscience data and models

**Cantarelli M, Marin B, Quintana A, Earnshaw M, Court R, Gleeson P, Dura-Bernal S, Silver RA, Idili G** (2018). Philosophical Transactions of the Royal Society B: Biological Sciences, 373(1758), 20170380.

## Abstract

Geppetto is an open-source platform that provides generic middleware infrastructure for building both online and desktop tools for visualizing neuroscience models and data and managing simulations. Geppetto underpins a number of neuroscience applications, including Open Source Brain (OSB), Virtual Fly Brain (VFB), NEURON-UI and NetPyNE-UI.

## Key Contributions

- Modular architecture for neuroscience applications
- Geppetto Model Abstraction for heterogeneous data
- Integration with NEURON, NetPyNE, NeuroML
- Web-based visualization components
- Applications: OSB, VFB, NEURON-UI, NetPyNE-UI, Virtual Fly Brain
