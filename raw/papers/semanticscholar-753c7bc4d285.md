## Abstract

Sustained attention is crucial for daily tasks, yet individualized prediction based on accessible neuroimaging like electroencephalography (EEG) remains scarce. To address this gap, this study developed an individualized predictive framework using functional connectivity (FC) and brain network metrics extracted from EEG during a psychomotor vigilance test (PVT). Connectome-based predictive modeling (CPM) was employed for FC and stepwise regression for network metrics, followed by a decision-level fusion strategy to integrate both features. Results demonstrated that models based on negative FC (r = 0.241) and network metrics (r = 0.345) both significantly predicted sustained attention measures, while the fusion model achieved superior performance. Contributing features were dominated by left-hemispheric, low-frequency (i.e., delta and theta) connectivity. Notably, poorer attention correlated with increased delta-band small-worldness and local efficiency, suggesting a neural compensatory mechanism. Overall, the work validates a multimodal feature fusion approach for EEG-based cognitive prediction and provides quantitative evidence of neural mechanisms underlying sustained attention.
