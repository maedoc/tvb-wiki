# BRAPH 2.0 Genesis: An Open-Source Toolbox for Brain Connectivity Analysis

**Authors:** Mijalkov et al.  
**Year:** 2021  
**Venue:** Frontiers in Neuroinformatics

## Key Contributions

- Introduction of BRAPH 2.0 (Genesis) with enhanced capabilities
- Major redesign of the original BRAPH toolbox
- Improved workflow for brain network construction and analysis
- New features for community detection and network comparison
- Enhanced visualization capabilities

## Abstract Summary

BRAPH 2.0 Genesis represents a major update to the original BRAPH toolbox, introducing a redesigned architecture with enhanced analysis capabilities. The new version offers improved workflow integration, expanded graph theory metrics, and better visualization tools for brain connectivity analysis. BRAPH 2.0 maintains the multimodal support of its predecessor while providing a more flexible and extensible framework for connectomics research.

## Significance

BRAPH 2.0 Genesis addresses limitations of the original BRAPH software while maintaining its accessibility and versatility. The new version has been adopted by researchers studying brain network alterations in various neurological and psychiatric conditions.
