## Abstract

This paper proposes a novel deep-learning-based voltage security assessment framework that evaluates $N-1$ contingencies across varying network topologies without explicit AC power flow computations. Topology-specific expert models are trained to predict a system-wide voltage violation index, which provides a fast and reliable voltage security metric. The methodology is validated using the B37 test system, incorporating 58 different network topologies, including the base case and scenarios with individual transmission line outages. Power system modeling and synthetic data generation are performed using the PowerWorld Simulator, while the deep neural network training and evaluation utilize Python. An $R^{2}$ score of 0.9876, together with inference times of up to 43 ms, demonstrates the proposed method's high accuracy and its suitability for real-time voltage control and cybersecurity applications in power systems.
