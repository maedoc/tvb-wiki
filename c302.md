The c302 model framework is a computational platform for generating network models of the [[c-elegans|nematode Caenorhabditis elegans]] nervous system, developed as part of the [[openworm]] project. The name "c302" refers to the 302 neurons that comprise the complete connectome of the adult C. elegans hermaphrodite, making it one of the few complete neural connectome models available in computational neuroscience [[1]](https://royalsocietypublishing.org/doi/10.1098/rstb.2017.0379).

## Overview

The c302 framework allows researchers to generate neuronal network models at multiple levels of anatomical and physiological detail, from simplified [[neuron]] representations to biophysically detailed conductance-based models. Unlike traditional single-neuron models, c302 models the entire nervous system of an organism—the nematode C. elegans—enabling whole-organism simulations of neural activity and behavior [[2]](https://ncbi.nlm.nih.gov/pmc/articles/PMC6158223/).

C. elegans has been a foundational organism in neuroscience due to its completely mapped nervous system. Every neuron has been named, its connections documented, and its role in various behaviors characterized. The c302 framework leverages this wealth of connectomic data to create computational models that can be simulated and analyzed using standardized tools and formats [[3]](https://docs.openworm.org/Projects/c302/).

## Key Features

The c302 framework offers several distinctive capabilities that set it apart from other neural modeling approaches. First, it provides a choice of four parameter sets representing increasing levels of biophysical detail: Parameter Set A uses leaky integrate-and-fire (LIF) neurons with spike-triggered synaptic transmission; Parameter Set B adds firing rate-based activity modeling and gap junction connections; Parameter Set C implements single-compartment, conductance-based neurons with Hodgkin-Huxley style ion channels; and Parameter Set D extends this to multicompartmental neurons with detailed morphologies [[1]](https://royalsocietypublishing.org/doi/10.1098/rstb.2017.0379).

Second, the framework supports flexible network configurations. Users can generate models containing all 302 neurons and 96 muscle cells of the full hermaphrodite, or any subset thereof—such as the 20-neuron pharyngeal circuit or the motor circuits involved in locomotion. This modularity enables researchers to focus on specific neural subsystems without the overhead of the complete nervous system.

Third, c302 generates models in the standardized [[neuroml]] 2 format, which is based on the LEMS (Low Entropy Model Specification) language. This standardization ensures interoperability with a wide range of simulation engines and visualization tools, including [[neuron]], [[nest]], jNeuroML, pyNeuroML, and the Open Source Brain platform [[4]](https://github.com/openworm/c302).

Fourth, the framework supports multiple synapse types including chemical synapses (excitatory and inhibitory) and electrical gap junctions. Importantly, c302 implements analogue synaptic transmission—a continuous form of synaptic communication that better represents C. elegans neuromuscular junction physiology than the spike-triggered approach commonly used in vertebrate models [[2]](https://ncbi.nlm.nih.gov/pmc/articles/PMC6158223/).

## Relationship to TVB

The c302 framework relates to [[the-virtual-brain]] through the broader context of [[neural-mass-models]] and whole-brain modeling methodologies. While TVB operates at the level of brain regions rather than individual neurons, c302 exemplifies multiscale modeling approaches that bridge cellular-level dynamics with network-level phenomena. The techniques developed for c302—particularly parameter optimization, connectivity specification, and model validation—have informed mean-field approximations used in larger-scale brain simulations.

Researchers working on [[personalized-brain-modeling]] may draw inspiration from c302's approach to constraining models with empirical connectivity data. The framework demonstrates how detailed single-neuron and circuit-level models can inform the parameterization of population-level representations. Additionally, the NeuroML-based format allows c302-generated networks to interface with broader neuroscience modeling ecosystems that feed into whole-brain simulation frameworks.

## Key Papers

The c302 framework was first described in a 2018 publication in Philosophical Transactions of the Royal Society B:

> Gleeson P, Lung D, Grosu R, Hasani R, Larson SD. (2018). "c302: a multiscale framework for modelling the nervous system of Caenorhabditis elegans." Phil. Trans. R. Soc. B 373:20170379. [[DOI]](https://doi.org/10.1098/rstb.2017.0379)

This paper established the technical foundation of the framework and demonstrated its application through a case study of forward locomotion circuit modeling. The authors showed that conductance-based single-compartment models could generate traveling waves of muscle activity resembling natural worm locomotion [[1]](https://royalsocietypublishing.org/doi/10.1098/rstb.2017.0379).

Additional foundational works include the OpenWorm project overview (Szigeti et al., 2014) and the NeuroML 2 specification (Cannon et al., 2014), which provide the broader context for c302's development.
